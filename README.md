# Real Engineer

A welcoming starting point for learning the ideas behind great software:
system design, data structures and algorithms, computer networks, machine
learning, and deep learning.

## Run it

```sh
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Structure

- `src/pages/` – page components, including the landing page
- `src/components/` – reusable UI and animation components
- `src/data/topics.js` – registry for future topic lessons
- `src/styles/global.css` – global styles and responsive landing-page styling
- `index.html` – document metadata and font loading
